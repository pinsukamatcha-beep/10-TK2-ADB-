# X-TK2 — SMK Negeri 1 Adiwerna

Website kelas X-TK2, jurusan Teknik Ketenagalistrikan (TITL), SMK Negeri 1 Adiwerna.
Bertema panel listrik/kelistrikan dan interaktif — halaman baru menampilkan konten
setelah saklar power di-tekan.

## Isi website

- **Panel utama** — saklar power interaktif dengan efek percikan listrik
- **Tentang kelas** — profil singkat X-TK2
- **Struktur pengurus** — kartu breaker yang bisa di-tap untuk menampilkan nama pengurus
- **Galeri foto** — dokumentasi kelas dengan lightbox
- **Link Instagram kelas** dan **lokasi sekolah** (Google Maps)

## Struktur file

```
.
├── index.html      # struktur halaman
├── style.css       # semua styling
├── script.js       # logika interaktif (saklar, galeri, struktur organisasi)
└── README.md
```

## Cara menjalankan

Buka `index.html` langsung di browser, atau aktifkan **GitHub Pages** dari
pengaturan repository ini (Settings → Pages → pilih branch `main` / folder root)
supaya website bisa diakses lewat link publik.
